개인정보처리방침

시행일: 2026년 7월 21일 | 최종 수정: 2026년 7월 21일
이용약관 · English

TalkFit(이하 "서비스")은 이용자의 개인정보를 소중히 여기며, 개인정보보호법 및 관련 법령을 준수합니다.

1. 수집하는 개인정보

  • Google 로그인 시: 이메일 주소, 표시 이름, 프로필 사진 URL, 계정 고유 식별자(UID)
  • 학습 활동: 학습 기록, XP, 레벨, 연속 학습일, 퀴즈 결과
  • 사용자 입력 텍스트: AI 분석을 위해 입력한 한국어/영어 텍스트
  • 업로드한 음성 파일: 받아쓰기·분석을 위해 직접 업로드한 오디오 파일 (최대 4MB)
  • YouTube 영상 URL: 영상 학습 기능에서 이용자가 입력한 링크
  • 피드백: 베타 피드백 폼을 통해 제출한 의견, 제출 시점의 이메일(로그인한 경우)과 브라우저·기기 정보(User-Agent 일부)
  • 자동 수집: AI 기능 남용 방지를 위한 접속 IP 주소(서버 메모리에 당일 요청 횟수 계산 목적으로만 사용, 매일 초기화)

서비스는 주민등록번호, 결제 정보, 위치 정보, 연락처를 수집하지 않습니다.

2. 개인정보의 이용 목적

  • 학습 진행 상태 저장 및 기기 간 동기화
  • 리더보드 순위 산정 (이름 첫 단어, XP, 레벨, 연속 학습일이 표시됩니다)
  • AI 기반 영어 학습 서비스 제공 (문장 분석, 교정, 대화, 음성 받아쓰기, 영상 학습)
  • 서비스 개선을 위한 통계 분석 및 이용자 문의·피드백 대응
  • 비정상적인 이용 및 과도한 API 호출 방지

3. 개인정보의 보관 및 파기

  • 개인정보는 서비스 이용 기간 동안 보관됩니다.
  • 계정 삭제 시 서버(Firebase Firestore)에 저장된 학습 데이터, 리더보드 기록, 계정 정보를 즉시 파기합니다.
  • AI 처리를 위해 전송한 텍스트·음성·영상 URL은 서비스 서버에 별도로 저장하지 않습니다. 다만 처리 위탁사(Google)의 보관 정책은 해당 사업자의 약관을 따릅니다.
  • 관련 법령에 따라 일정 기간 보관이 필요한 경우 해당 기간 동안 보관 후 파기합니다.

4. 개인정보의 제3자 제공 및 처리 위탁

서비스는 이용자의 동의 없이 개인정보를 판매하거나 제3자에게 제공하지 않습니다. 다만 서비스 제공에 필요한 범위에서 아래와 같이 처리를 위탁합니다:

  • Google Gemini API: AI 학습 기능 제공을 위해 이용자가 입력한 한국어/영어 텍스트, 업로드한 음성 파일, 입력한 YouTube 영상 URL이 전송됩니다. 이름·이메일 등 계정 식별 정보는 함께 전송되지 않습니다.
  • Firebase (Google): 계정 인증 및 학습 데이터 저장
  • Vercel: 앱 호스팅 및 접속 통계
  • 법령에 의한 요청이 있는 경우

입력한 내용 자체에 개인정보가 포함될 수 있으므로, 타인의 개인정보나 민감한 정보는 입력·업로드하지 않도록 주의해 주세요.

녹음 모드는 브라우저에 내장된 음성 인식 기능(Web Speech API)을 사용하며, 이 경우 음성이 브라우저 제공자(예: Google, Apple)의 서버로 전송될 수 있습니다.

5. 이용자의 권리

  • 열람/수정: 설정 화면에서 계정 정보와 학습 기록을 확인할 수 있습니다.
  • 계정 삭제(앱 내): 설정 → 계정 → 계정 삭제에서 직접 계정을 영구 삭제할 수 있습니다. 삭제 시 학습 기록·XP·레벨·연속 학습일, 회화 분석 기록, 리더보드 등록 정보, 기기에 저장된 로컬 데이터, 그리고 로그인 계정 자체가 모두 삭제되며 복구할 수 없습니다.
  • 이메일 요청(대체 수단): 앱 내 삭제가 정상 동작하지 않는 경우 아래 문의처로 요청하시면 확인 후 삭제해 드립니다.
  • 로컬 데이터 삭제: 로그아웃 후 브라우저 데이터를 삭제하면 기기에 남은 데이터가 제거됩니다.

6. 만 14세 미만 아동의 개인정보

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 만 14세 미만 아동의 개인정보를 고의로 수집하지 않습니다. 만 14세 미만 아동이 법정대리인의 동의 없이 개인정보를 제공한 사실을 확인한 경우, 해당 정보를 지체 없이 파기합니다. 법정대리인은 아래 문의처로 확인 및 삭제를 요청할 수 있습니다.

7. 외부 서비스

  • Firebase Authentication / Firestore (Google): 인증 및 데이터 저장. Firebase 개인정보처리방침
  • Firebase Analytics (Google Analytics for Firebase): 서비스 이용 통계 측정. Google 개인정보처리방침
  • Vercel: 앱 호스팅 및 웹 분석. Vercel 개인정보처리방침
  • Google Gemini API: AI 분석·받아쓰기·음성 합성 기능. Gemini API 이용약관
  • YouTube Data API (Google): 영상 제목·채널 검색 정보 조회. Google 개인정보처리방침

서비스는 광고를 게재하지 않으며, 광고 SDK를 포함하지 않고, 개인정보를 판매하지 않습니다.

8. 쿠키 및 로컬 저장소

서비스는 학습 진행 상태를 브라우저 localStorage에 저장합니다. 로그인하지 않은 게스트 모드에서는 sessionStorage를 사용하며, 브라우저 탭을 닫으면 데이터가 사라집니다. 이는 서비스 제공에 필수적이며, 브라우저 설정에서 삭제할 수 있습니다.

9. 안전성 확보 조치

  • 모든 통신은 HTTPS로 암호화됩니다.
  • AI API 키는 서버 환경 변수로만 관리되며 앱에 노출되지 않습니다.
  • 학습 데이터는 로그인한 본인 계정에서만 읽고 쓸 수 있도록 접근이 제한됩니다.

10. 방침의 변경

본 방침이 변경되는 경우 시행일과 변경 내용을 본 페이지에 게시합니다. 중요한 변경은 서비스 내에서 별도로 안내합니다.
